# CASCADE 프로토타입 — 막대·중력·흐름 (VR 포함)

이 폴더만 통째로 옮기면 됩니다. 인터넷 연결 없이 동작합니다 (three.js 포함).

```
index.html      Stage 1
stage2.html     Stage 2 (중력이 세고 목표가 높다)
milky.js        엔진 — 두 스테이지가 공유한다
milky.css       스타일 — 두 스테이지가 공유한다
three.min.js    three.js r128 (MIT)
audio/bgm.mp3   배경음 (원하는 mp3 로 바꾸면 됩니다)
```

스테이지 차이는 각 HTML 맨 아래 `window.MILKY_STAGE` 한 덩어리가 전부입니다.
중력·목표 높이·필요 상향량·연결 예산을 거기서 조정하세요. 엔진은 그 값만 읽습니다.

## 배경음

`audio/bgm.mp3` 로 파일을 하나 넣으면 START 를 누르는 순간 재생되고 반복됩니다.
파일이 없거나 `file://` 로 열어서 못 읽으면, 아래 **음악 / Music** 버튼으로
직접 고를 수 있습니다 (서버 없이 동작).

## 처음 화면

바닥의 원 위에 점 세 개를 찍어 삼각형을 닫으면 **START** 가 나타납니다.
누르면 시점이 비스듬히 돌아가며 게임이 시작됩니다. 몰입 기기에서는 눈앞에
떠 있는 START 판을 트리거로 누르면 됩니다.

언어는 우상단 버튼으로 한국어 / English 를 바꿉니다.

## 데스크톱에서 열기

`index.html` 을 더블클릭하면 그냥 열립니다.

## VR 에서 열기 (Quest, Vision Pro 등)

WebXR 은 **보안 컨텍스트(HTTPS 또는 localhost)** 를 요구합니다. `file://` 로 열면
VR 버튼이 나타나지 않습니다. 같은 와이파이에 있는 PC 에서 서버를 띄우고
헤드셋 브라우저로 접속하는 것이 가장 간단합니다.

```bash
# 이 폴더에서
python3 -m http.server 8080
```

헤드셋 브라우저에서 `http://<PC의 IP>:8080` 접속.

Quest 브라우저는 사설 IP 의 http 를 보안 컨텍스트로 취급하지 않는 경우가 있습니다.
그때는 HTTPS 가 필요합니다. 가장 쉬운 방법:

```bash
# Quest 를 USB 로 연결한 뒤 (adb 필요)
adb reverse tcp:8080 tcp:8080
# 헤드셋에서 http://localhost:8080 으로 접속 — localhost 는 보안 컨텍스트다
```

또는 `npx serve --ssl-cert ... --ssl-key ...` 같은 도구로 HTTPS 를 띄웁니다.

## 조작

| | 데스크톱 | VR |
|---|---|---|
| 놓기 / 받치기 | 클릭 | 트리거 |
| 시점 회전 | 드래그 | 고개 |
| 축 이동 | 두 손가락 스크롤 | **양손 그립 후 나란히 이동** |
| 확대 / 축소 | 두 손가락 벌리기, 휠, 우하단 버튼 | **양손 그립 후 벌리기 / 조이기** |

VR 에서는 구조물이 눈앞의 탁상 모형으로 나타납니다. 양손 그립으로 원하는
크기와 위치로 옮겨서 보면 됩니다.

## 규칙

- 세운 막대는 **쓰러진다**. 막대 3개가 붙어야 멈춘다 (삼각형은 경첩, 사면체는 강체)
- 공중 자리 = **올리는 수**, 바닥 자리 = **넓히는 수**
- 상향 흐름 = 접점 수 ÷ (1 + 높이). **높이를 올릴수록 바닥을 넓혀야 한다**
- 클리어 = 높이 2.8 이상 **그리고** 상향 1.0 이상
